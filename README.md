# lodexa-ai-redirect

GitHub Pages site for the secondary domain lodexa.se (custom domain in CNAME). Every path redirects client-side to the same path on https://lodexa.ai (index.html and 404.html are identical).

The repo name is historical: it used to redirect lodexa.ai to lodexa.se before lodexa.ai became the primary domain (2026-10-09).
